## Examples

### Re-planning

Agents change their mind. Insert a step with a new `id` and it slides in while the rail extends:

```tsx
setSteps((steps) => {
  const i = steps.findIndex((s) => s.id === "deploy");
  return [...steps.slice(0, i), { id: "a11y", title: "Accessibility pass", status: "todo" }, ...steps.slice(i)];
});
```

### Compact variant

```tsx
<AgentPlan title="Exporting" steps={steps} variant="compact" collapsible={false} />
```

### Pairing with ToolCall

```tsx
{
  id: "search",
  title: "Research competitors",
  status: "active",
  meta: <ToolCall name="search_web" title="Searching the web" status="running" startedAt={t0} />,
}
```

### Failed step with retry

```tsx
{
  id: "images",
  title: "Create illustrations",
  status: "failed",
  meta: <button onClick={retryFromImages}>Retry from here</button>,
}
```

## Accessibility

- The plan is a list; the active step has `aria-current="step"` and every step has a visually hidden status (“completed”, “in progress”).
- The header bar is a `role="progressbar"` with `aria-valuenow`.
- With reduced motion: no ripple, no rail fill animation, no shake.
