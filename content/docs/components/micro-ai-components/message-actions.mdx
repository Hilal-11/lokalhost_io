## Usage

```tsx
import { MessageActions, BranchSwitcher, BranchContent } from "@/components/lokalhost_io/micro-ai-components/message-actions/message-actions";

<Message>
  <BranchContent current={version}>
    <Message.Content content={versions[version - 1]} />
  </BranchContent>
  <div className="flex items-center gap-1">
    <BranchSwitcher current={version} total={versions.length} onChange={setVersion} />
    <MessageActions visibility={isLatest ? "always" : "hover"}>
      <MessageActions.Copy text={versions[version - 1]} />
      <MessageActions.Feedback onFeedback={onFeedback} />
    </MessageActions>
  </div>
</Message>
```

`visibility="hover"` relies on an ancestor with Tailwind's `group/message` class — `<Message>` adds it for you. If you use your own wrapper, add `className="group/message"` to it.

### Persisting feedback

```ts
const onFeedback = async (value: "up" | "down" | null, reason?: string, comment?: string) => {
  await fetch(`/api/messages/${messageId}/feedback`, {
    method: "POST",
    body: JSON.stringify({ value, reason, comment }),
  });
};
```

### Branch data model

Keep every version of a message and the index the user is looking at:

```ts
type MessageBranch = {
  messageId: string;
  current: number; // 1-based
  versions: { id: string; content: string; model: string; createdAt: string }[];
};
```

Regenerating pushes a new version and moves `current` to it; editing a user message creates a new branch for everything after it.

## Keyboard

| Key | Action |
| --- | --- |
| `←` / `→` | Move between toolbar buttons (roving focus) |
| `Home` / `End` | First / last button |
| `Shift` + click Copy | Copy plain text instead of markdown |
| `←` / `→` on the branch switcher | Previous / next version |
| `↑` / `↓` in menus | Move between items |

## Accessibility

- The bar is a `role="toolbar"` with one tab stop and arrow-key roving focus.
- Feedback buttons expose `aria-pressed`; copy success is announced through a live region.
- Every icon button has a label and a tooltip after 300ms.
- With reduced motion: no particles, no spinning, icons swap with a simple fade.
