## Status reference

| Status | Icon | Card |
| --- | --- | --- |
| `pending` | Hollow circle | Queued, no duration |
| `running` | Spinning arc | Title shimmers, duration ticks live |
| `awaiting-approval` | Ring with pulsing dot | Highlighted, breathing border, Deny / Approve |
| `success` | Circle fills, check draws in | Duration freezes |
| `error` | X draws in | Card shakes once, error banner with Retry |
| `cancelled` | Dashed circle with a dash | Muted |

## Examples

### Approval flow

```tsx
<ToolCall
  name="send_email"
  title="Send summary to the team"
  status={status}
  input={args}
  approvalDescription="Sends one email to team@example.com. This can't be undone."
  onApprove={async () => {
    setStatus("running");
    await runTool(args);
    setStatus("success");
  }}
  onDeny={() => setStatus("cancelled")}
/>
```

When the card is focused, `Enter` approves and `Esc` denies.

### Custom output renderer

```tsx
<ToolCall
  name="search_web"
  status="success"
  output={{ results }}
  renderOutput={(output) => (
    <ul>
      {(output as { results: Result[] }).results.map((r) => (
        <li key={r.url}>{r.title}</li>
      ))}
    </ul>
  )}
/>
```

### With the Vercel AI SDK

Map tool parts to cards. Approval maps onto tools that return `needsApproval`, or onto your own confirmation step before you call `addToolResult`.

```tsx
const STATE: Record<string, ToolCallStatus> = {
  "input-streaming": "pending",
  "input-available": "running",
  "output-available": "success",
  "output-error": "error",
};

<ToolCallGroup>
  {message.parts
    .filter((p) => p.type.startsWith("tool-"))
    .map((p) => (
      <ToolCall
        key={p.toolCallId}
        name={p.type.replace("tool-", "")}
        status={STATE[p.state] ?? "pending"}
        input={p.input}
        output={p.output}
        error={p.errorText}
      />
    ))}
</ToolCallGroup>
```

## Accessibility

- The card header is a button with `aria-expanded`; collapsed content is `inert`.
- Status changes are announced politely, e.g. “search_web succeeded in 1.4 seconds”.
- Approve / Deny buttons include the tool name in their labels.
- With reduced motion the spinner becomes a pulsing opacity and the error shake is skipped.
