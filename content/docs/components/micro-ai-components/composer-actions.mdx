## Keyboard

| Key | Action |
| --- | --- |
| `Enter` / `Space` on the trigger | Open the menu and focus the first row |
| `↑` / `↓`, `Home` / `End` | Move between rows |
| `Esc` | Close and return focus to the trigger |
