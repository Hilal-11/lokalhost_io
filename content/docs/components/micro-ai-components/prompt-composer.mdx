## Usage

### Basic

```tsx
import PromptComposer from "@/components/lokalhost_io/micro-ai-components/prompt-composer/prompt-composer";

<PromptComposer onSubmit={(text) => send(text)} status={status} onStop={stop} />
```

### With attachments

Paste an image, drag files anywhere onto the composer, or use the paperclip. Pass `onUpload` to show progress rings and errors:

```tsx
<Composer
  onSubmit={(text, files) => send(text, files)}
  onUpload={async (file, onProgress) => {
    await uploadWithProgress(file, onProgress); // throw to show the error + Retry state
  }}
>
  <Composer.Attachments />
  <Composer.Input />
  <Composer.Toolbar>
    <Composer.AttachButton accept="image/*,.pdf" />
    <Composer.Spacer />
    <Composer.Submit />
  </Composer.Toolbar>
</Composer>
```

### With a model picker

```tsx
const models = [
  { id: "fast", label: "Fast", description: "Quick answers" },
  { id: "smart", label: "Smart", description: "Balanced" },
  { id: "reasoning", label: "Reasoning", description: "Thinks longer" },
];

<Composer.ModelChip models={models} value={model} onChange={setModel} />
```

### Controlled

```tsx
const [value, setValue] = useState("");

<Composer value={value} onValueChange={setValue} onSubmit={send}>
  <Composer.Input />
  <Composer.Toolbar>
    <Composer.Spacer />
    <Composer.Submit />
  </Composer.Toolbar>
</Composer>
```

## Keyboard

| Key | Action |
| --- | --- |
| `Enter` | Send (never while an IME is composing — safe for Hindi, Japanese, Chinese input) |
| `Shift` + `Enter` | New line |
| `⌘` / `Ctrl` + `Enter` | Send |
| `Esc` | Stop generating while streaming |
| `↑` (empty input) | Recall the last sent message (needs `history`) |
| `↑` / `↓` | Move through models when the model popover is open |

## Accessibility

- The textarea has an `aria-label`; the submit button switches between “Send message” and “Stop generating”.
- Attachments are a `role="list"`; each remove button is labelled with the file name.
- Dragging files over the composer is announced through a polite live region.
- With reduced motion the button morph, chip pops and typewriter fill become instant.
