## Usage

```tsx
import DownloadButtonGroup, { DownloadButton } from "@/components/lokalhost_io/buttons/download-button";

// All three platforms; the visitor's OS becomes the primary button
<DownloadButtonGroup highlightDetected config={{ mac: { downloadUrl: "/app.dmg" } }} />

// A single button
<DownloadButton platform="mac" as="a" href="/app.dmg" fileName="App.dmg" variant="primary" size="lg" />
```

Hovering (or keyboard-focusing) rolls the label up while an identical copy rolls in from below. Pressing scales the button to 0.97. Every platform ships with a monochrome icon; pass `icon` to replace it.

### Custom colors

The default look is monochrome. To match a brand, swap only the colors — shape, size and shadows stay intact:

```tsx
<DownloadButton
  platform="mac"
  colorClassName="bg-zinc-900 text-white border border-zinc-950 hover:bg-black"
  wrapperColorClassName="bg-zinc-800 text-white"
/>
```
